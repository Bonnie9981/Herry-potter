# 霍格華茲人生模擬器｜總入口

本 repository 支援**多次、彼此獨立的模擬**。每次模擬都有自己的角色、家庭、能力、物品、關係、事件時間線與存檔；跨模擬共用的只有遊戲系統規則、世界觀參考與資料管理規範。

## 核心資料管理原則

1. **每次模擬獨立**：不得把某次角色的天賦、家庭、物品、經歷或人際關係帶入下一次模擬，除非玩家明確要求跨模擬沿用。
2. **全域規則共用**：敘事規則、世界觀、能力判定、魔法分類與存檔格式放在 `global/`。
3. **模擬資料分開**：每次模擬放在 `simulations/SIM-編號/`，不可混存。
4. **能力必須細分**：科目天賦、子領域天賦、單一咒語、單一魔藥配方、知識、熟練度與實際表現分開記錄。
5. **魔法目錄依原著細分**：咒語需按用途／魔法類型分組並逐項記錄；魔藥需逐項記錄配方、材料、製作步驟、難度、效果及角色掌握程度。不可只用「魔咒滿級」「魔藥滿級」一行帶過。
6. **資料未確認就標示未確認**：不可自行把未學過、未測試或未證實的能力寫成已掌握。
7. 每次遊戲對話結束，依實際變動更新對應檔案。GitHub 寫入成功後才可回報已存檔。

## 資料夾導覽

- `global/`：跨模擬共用規則、能力系統、魔法百科索引、世界觀參考。
- `simulations/`：所有模擬的總索引。
- `simulations/SIM-XXX/`：單次模擬完整資料。
