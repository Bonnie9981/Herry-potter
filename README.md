## 存檔維護規則

1. 每次遊戲對話結束時更新 GitHub 存檔。
2. 依照分類更新對應檔案，不將所有資訊混成一份摘要。
3. 事件時間線只記錄實際發生的事；尚未確認的事項標示為等待／未決。
4. 保留既有設定與歷史，不擅自覆蓋或改寫。
5. 每次更新後回報實際更新的檔案與 commit。
6. 不得宣稱已存檔，除非 GitHub 寫入成功。
7. 每個角色的天賦都必須有獨立表格，分開列出天賦等級與真實實力；天賦不得直接當成科目知識或技能熟練度。

## 目前進度

- 尚未分院、尚未正式入學。
- 已取得魔杖、完成一年級用品採購。
- 已收養白化球蟒「小羽」，正在等待霍格華茲入校許可。
- 洛夏已學會漂浮咒，展現優秀的初期控制能力。
- 本次洛夏各項天賦皆滿級；各領域的真實實力依實際學習與經歷獨立更新。
