# 場景背景素材交付規格（給 ChatGPT 美術）

大廳、庭院、移動樓梯廊、魔咒學教室、溫室、黑湖湖畔六個場景的背景改由 ChatGPT 繪製。程式端（Claude）負責把碰撞、遮擋、互動點和 NPC 站位對到圖上。照下面的規格交圖，就能直接對位。

畫風、指令與各場景內容見同資料夾的 `PROMPTS.md`，構圖參考見 `<場景>-layout.png`。

## 1. 每個場景要交的檔案

| 檔案 | 必要 | 說明 |
|---|---|---|
| `<id>-bg.png` | 必要 | 完整背景，**不含人物、文字、UI**。 |
| `<id>-fg.png` | 建議 | 前景遮擋層：只保留會擋住角色的物件（欄杆、桌子前緣、柱子、吊燈等），其餘透明。尺寸與 bg 完全相同、位置完全對齊。 |
| `<id>-walk.png` | 選用 | 可走區域遮罩：可走的地面塗白、不可走塗黑。沒有的話由 Claude 依 bg 自己描。 |

`<id>`：`hall`、`courtyard`、`corridor`、`classroom`、`greenhouse`、`grounds`。

## 2. 圖片規格

- 尺寸 **1920 × 1080（16:9）**，PNG。fg 要有透明背景（RGBA）。
- 鏡頭與 `assets/art-direction/霍格華茲圖書館奇遇-2.png` 相同：2.5D 斜俯視角，從右前方往左後方看，左牆與後牆可見，前方和右側只放矮欄杆。**同一個場景的 bg、fg、walk 不能換角度或重新構圖。**
- 地面中間要留出大塊可走的空地；地面不要被前景大物件整片擋住。
- 角色比例參考：一名學生站在畫面中央，身高約占畫面高度的 **13%**（約 140 px），和參考圖一致。家具比例照這個身高抓。
- 入口要畫得出來：每個場景的出口位置（見下表）要看得出門、拱門、步道或樓梯。

## 3. 各場景必須出現的出口與互動物件

| 場景 | 出口（通往） | 互動物件（程式 hotspot id） |
|---|---|---|
| hall 大廳 | 後牆右側木門 → 移動樓梯廊；前方中央開口 → 庭院 | 公告欄 `notice`、門邊肖像 `portrait`、學院長桌 `table` |
| courtyard 庭院 | 後牆中央大門 → 大廳；右側 → 溫室；前方中央 → 黑湖湖畔 | 噴泉 `fountain`、學生聚集處 `students` |
| corridor 移動樓梯廊 | 前方 → 大廳；右側 → 魔咒學教室；第一段上樓梯口 → 圖書館 | 移動樓梯 `stairs`、會說話的肖像 `portrait2` |
| classroom 魔咒學教室 | 前方 → 移動樓梯廊 | 黑板 `board`、練習器具 `tools` |
| greenhouse 溫室 | 左側玻璃門 → 庭院；前方 → 黑湖湖畔 | 苗床植物 `plant`、工作台旁助教位置 `assistant` |
| grounds 黑湖湖畔 | 前方小徑 → 庭院；右側林邊小徑 → 溫室 | 棧橋盡頭湖面 `lake`、林間小徑 `path` |

NPC 需要的具名站位（每場景至少要有「中央」）見 `docs/js/scenes/<id>.js` 的 `npcSpots`；只要地面有對應的空地即可，不必在圖上標示。

## 4. 交付位置

- 直接 commit 到 `assets/scenes/<id>/`（例如 `assets/scenes/hall/hall-bg.png`），或貼到協作 Issue。
- 每次交圖附一句說明：場景、第幾版、和上一版差在哪。
- Claude 收到後會產出「背景＋碰撞框＋互動點」疊圖截圖回貼，確認對位後才放進遊戲。

## 5. 驗收

- 畫風：與參考圖並排看不出是不同人畫的（色調、筆觸、光影、鏡頭）。由將軍確認。
- 對位：疊圖截圖上，碰撞框貼齊家具與牆、互動點落在對應物件上、出口落在門或步道上。
