## 本次自我紅隊結果

1. **QA 語意脆弱性**：第一次測試因文件沒有使用固定詞彙「人工核准／不自動合併」而失敗。修正後明確寫入權限條款，四項測試通過。後續應避免把大量自然語言規則全部綁定單一措辭，必要時改用結構化欄位。
2. **報告保存期限**：QA Artifact 目前保留 14 天，只適合短期除錯；長期趨勢應以去識別化摘要或版本化報告保存，不能把私人遊戲內容上傳。
3. **自動化能力邊界**：CI 只能驗證檔案、關鍵規則與測試程式，不能判斷角色演出是否自然、謎題是否公平或主持者是否真正理解玩家意圖。這些仍需要情境測試與真人品鑑。
4. **Pages 部署偶發失敗**：第一次部署遇到 GitHub Pages API 暫時找不到同次 run 的 artifact；重跑部署 job 後成功。入口檢查本身成功，故記為平台暫時性部署問題，而非 HTML 驗證失敗。
5. **外部審查聲明**：本次是自我紅隊，不是獨立第三方或真人玩家實測；正式公開測試前仍需招募不同玩法的測試者。

## 已知範圍與限制
- QA 只能檢查可形式化的規則與檔案結構，不能證明劇情有趣、NPC 表演自然或主持者永遠正確。
- 自我紅隊不是外部獨立審查；需要真人玩家或獨立 Agent 才能稱為外部驗證。
- 網頁入口目前產生開局指令與角色 JSON；不是雲端遊戲伺服器，也不會自動保存 AI 對話。
- GitHub Actions 不使用模型 API。玩家在 ChatGPT 免費版使用對話仍受產品本身使用額度限制。
