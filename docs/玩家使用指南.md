# 玩家使用指南

## 開始遊玩

1. 開啟 [霍格華茲人生模擬器入口](./index.html)。
2. 填寫角色資料，選擇世界模式與遊戲節奏。
3. 按「生成我的開局指令」，複製後貼到 ChatGPT 或其他相容的 AI 對話工具。
4. 依主持人引導確認角色設定，再開始故事。

## 保存進度

入口網站目前只提供角色設定 JSON 匯出／匯入。它不會自動保存 AI 對話，也沒有雲端存檔。遊玩時請定期要求主持人輸出完整存檔，將存檔另存於自己的裝置；下次開新對話時，貼上主持規則與存檔即可接續。

## 世界模式

- **正典優先**：盡量遵循原著時間線與角色設定。
- **正典分歧**：保留原著世界觀，但玩家行動可以造成合理的時間線變化。
- **平行自由世界**：以魔法世界為基礎，允許更大幅度的自訂。

## 重要說明

- 每位玩家應使用自己的 AI 對話與存檔；入口不會讀取其他玩家資料。
- 網頁本身不提供 AI 推理服務，不會自動開啟 ChatGPT，也不會代替玩家送出訊息。
- 本專案為非官方粉絲創作，與原著權利人及 Wizarding World 無隸屬關係。
- 網站是公開的，請勿在角色設定或存檔中放入真實住址、密碼等敏感個資。
