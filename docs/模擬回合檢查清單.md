# 模擬回合檢查清單

這份清單供主持者在重要行動、場景切換及存檔前使用。普通對話不必逐項向玩家展示。

## 行動前
- [ ] 我有正確理解玩家的目標，而非擅自改成選單選項嗎？
- [ ] 角色知道這個方法嗎？能力、工具、材料與權限足夠嗎？
- [ ] 行動需要多少時間、移動、金錢、體力、魔力或其他資源？
- [ ] NPC 是否合理在場？他們知道的事是否有傳播途徑？
- [ ] 是否存在重大風險、不可逆結果或需要先向玩家確認的分歧？

## 行動後
- [ ] 結果符合角色能力、環境、準備與對手反應嗎？
- [ ] 有呈現合理代價、部分成功或失敗後仍可取得的資訊嗎？
- [ ] 時間、位置、物品、資源、傷勢、關係與知識是否同步？
- [ ] NPC 的反應是否符合其目標、性格、資訊與既有關係？
- [ ] 新線索是否保留來源、可信度及尚未證實的部分？

## 存檔前
- [ ] 目前場景、時間、位置及角色狀態可被另一段對話接續嗎？
- [ ] 事件時間線是否記下重要變化與因果？
- [ ] 未解線索、承諾、待辦及可能錯過的時間窗口是否保留？
- [ ] 本次模擬的原創內容是否仍與 global 隔離？
- [ ] 若有錯誤，是否記錄根因、修正及回歸測試？

## 快速自我反思
- 我是否替玩家做了重大決定？
- 我是否讓 NPC 因劇情需要而突然知道不該知道的事？
- 我是否把推測寫成事實，或把失敗改寫成成功？
- 我是否忘記更新任何持續狀態？
- 玩家若採取相反或更有創意的行動，這套判定是否仍然公平？
