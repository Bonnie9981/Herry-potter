# 高自由度霍格華茲模擬器：紅隊與玩家品鑑

- 審查對象：全域規則、開局流程、世界資料庫、模擬存檔架構
- 審查立場：假設陌生玩家會自由輸入未預期行動，並長期遊玩數週至數年
- 審查聲明：本文件是本次獨立批判性審查，不冒稱已由外部紅隊 Agent 或真人玩家實測。

## 一、總評

目前已具備不錯的世界觀資料分層、正典來源層級、能力／知識區分、多模擬隔離與基本主持風格，是可靠的資料底座。

但目前更接近「內容豐富、規則明確的互動小說主持指令」，還未達到可穩定支援陌生玩家長期遊玩的高自由模擬器。最大差距不是百科數量，而是自由行動判定、持續世界模擬、NPC 獨立性、狀態一致性、存檔恢復與新手引導尚未形成完整閉環。

建議暫不對外宣稱正式完成。先完成 P0 項目，再以多種玩家風格進行壓力測試。

## 二、紅隊發現

### P0：正式開放前必須解決

**RT-01｜選項制與自由行動尚未真正接軌**
現有指令提供最多四個選項及自由行動，卻沒有規定自由輸入如何解析、判定多步驟計畫與處理部分成功。風險是主持人只回應選項，忽略玩家創意。修正：採用高自由度模擬引擎的行動判定流程；選項永遠只是建議，不是行動白名單。

**RT-02｜世界狀態缺少統一資料模型**
目前有角色、時間線、物品、關係等檔案，但沒有完整規定日期、時間、位置、資源、NPC 行程、任務旗標及資訊傳播如何同步。風險是瞬間移動、物品重複、NPC 知情錯誤。修正：建立每次行動後的狀態更新清單與狀態快照格式。

**RT-03｜NPC 自主性只有原則，缺少運作程序**
「NPC 有自己的生活」仍不足以保證可執行。重要 NPC 需要目標、行程、知識、關係網及資訊傳播欄位。每個場景先檢查 NPC 當前位置、目標與合理知情範圍。

**RT-04｜開局問卷預設過多**
目前預設英國人、家庭經濟良好至富裕，並以固定選項描述性格、出身及家庭。這些可作快速預設，但不能成為硬性設定。修正：所有預設都可接受、修改或隨機；提供快速開局與深度設定兩種入口，未填欄位不必一次追問完。

**RT-05｜能力數值缺少可重現的判定規則**
0–100 天賦與施法維度已定義，但尚未說明分數如何影響成功、品質、速度、風險，以及主持人如何避免臨場任意改判。修正：定義無需檢定、對抗檢定、條件不足及敘事判定，不讓每個小動作都擲骰。

**RT-06｜存檔完整性與跨對話恢復缺少驗收標準**
目前要求更新 GitHub，卻未規定何時更新、哪些欄位同步、如何檢查矛盾或如何從中斷恢復。修正：重大事件後更新事件紀錄；每次結束前檢查最後事件 ID、最近確認時間及未同步項目。

**RT-07｜正典時間線與玩家介入的分歧管理不足**
角色生死、秘密曝光、物品取得等重大改變，不能只更新當下。需建立原著預期、玩家介入、立即結果、延遲影響與未確定後續的世界線差異表。

### P1：高優先改善

**RT-08｜魔法百科缺少可操作的標準條目**：統一咒語與魔藥欄位、來源證據、限制、反制、學年適用性與知識狀態。

**RT-09｜學校生活尚未形成年度循環**：建立學年日曆、課表、作業、考試、成績、活動、魁地奇與假期的執行規則。

**RT-10｜關係系統容易被簡化成好感度**：以信任、熟悉、尊重、敵意、競爭、嫉妒、依賴及浪漫吸引等多維狀態，加上事件依據記錄。

**RT-11｜玩家知識與角色知識未分離**：區分玩家知識、玩家角色知識、NPC 知識及主持人掌握的真相。

**RT-12｜自創設定衝突處理未標準化**：建立原創內容登錄表與衝突處理程序，未經玩家確認不得升級為全域通用。

**RT-13｜遊戲節奏缺少可調參數**：提供慢生活、校園戀愛、謎題探索、競爭、戰鬥或沙盒等偏好；敘事詳略、時間速度、危險程度與主線密度可在遊玩中調整。

**RT-14｜缺少新玩家教學與狀態查詢**：支援「查看狀態」「我的物品」「目前線索」「回顧上週」等自然語言查詢。

**RT-15｜支線失敗與錯過機會的公平性未定義**：線索需有可發現性、時間窗口、替代途徑與錯過後果，不要求玩家猜主持人心中的唯一正解。

## 三、玩家品鑑：不同玩家的壓力測試

| 玩家類型 | 可能行為 | 目前風險 | 通過標準 |
|---|---|---|---|
| 沙盒型 | 不上課，開店、研究魔法或旅行 | 被強迫回主線 | 能建立替代目標並追蹤資源與後果 |
| 社交型 | 維持多段友情、競爭與戀愛 | 關係失真 | NPC 有自己的生活，關係變化有事件依據 |
| 推理型 | 收集線索、提出錯誤假說 | 線索直接送答案 | 可驗證、反駁與修正假說 |
| 戰鬥型 | 挑戰高年級、違規施法 | 判定失衡 | 能力、情報、資源與風險有差距 |
| 創作者 | 自創咒語、家族、地點、制度 | 原創污染全域 | 能創作、隔離、標記與追蹤 |
| 原著粉 | 追問年份、角色、咒語 | 正典錯誤 | 可查來源層級，未知處標示待核對 |
| 隨性玩家 | 只說「去圖書館看看」 | 被追問太多 | 主持人能合理補足一般行動 |
| 破壞性測試者 | 利用漏洞、複製物品、刷能力 | 世界因果崩潰 | 能解釋限制與後果，不任意封鎖自由 |

## 四、目前設計中的具體問題

1. 舊版學院描述將史萊哲林與血統直接連結，應改以價值觀、選擇與特質分類，不能以血統作分類條件。
2. 「擅長科目」不可當成學院成員的固定能力，各學院學生都可能擅長任何科目。
3. 開局要求一次填寫大量資料，與高自由、低門檻的新玩家體驗不一致。
4. 「玩家需求優先」應解讀為尊重玩家玩法選擇，不代表世界規則、NPC 人格及因果都必須服從玩家。
5. 原著大方向是否固定，應由每次模擬選擇嚴格正典、允許玩家介入的正典分歧，或自由平行世界。
6. 每段一定列選項會讓遊戲像互動小說選單，應改為有助決策時才列。

## 五、開發順序

### P0：完成後再邀請外部玩家
- [ ] 自由行動判定流程。
- [ ] 世界狀態資料模型與每回合更新清單。
- [ ] 重要 NPC 自主運作與知識隔離。
- [ ] 存檔恢復與一致性檢查。
- [ ] 重寫開局引導，移除不可修改的預設。
- [ ] 定義正典分歧與自由平行世界模式。

### P1：形成完整遊戲循環
- [ ] 能力判定規則與檢定範例。
- [ ] 年度行事曆、課表、作業、考試、假期與活動循環。
- [ ] 多維關係系統。
- [ ] 玩家／角色／NPC／主持人知識分層。
- [ ] 原創內容登錄與衝突處理。
- [ ] 任務、線索、錯過機會與替代解法。

### P2：擴充內容與體驗
- [ ] 完整咒語與魔藥條目及來源核對。
- [ ] 生物、植物、物品、地點與人物資料庫。
- [ ] 新手指南、指令速查、狀態查詢。
- [ ] 多種玩家風格壓力測試。
- [ ] 回歸測試案例，避免修一項規則破壞其他玩法。

## 六、公開測試驗收標準

1. 新玩家不必讀完整規格即可開局。
2. 連續 20 種非選單行動仍能合理解析。
3. 同時追蹤至少 5 位重要 NPC 的行程、目標、知識與關係，無明顯矛盾。
4. 經過一週遊戲時間，日期、課表、物品、人物位置與事件紀錄一致。
5. 自創咒語、角色、地點與制度均能正確標記為本次模擬專屬。
6. 能處理規則漏洞並解釋限制與後果。
7. 新對話載入存檔後，能接續場景、人物狀態、未解線索與待決行動。
8. 玩家忽略主線數日，世界仍自然運作，不強迫回主線。
9. 狀態、物品、任務與關係查詢能與劇情一致。
10. 原著資訊不確定時標記未詳或待核對，不編造補齊。

## 七、結論

資料庫架構方向正確，能力分層與多模擬隔離值得保留；目前最大的缺口在執行層。下一階段優先順序應是：**自由行動引擎 → 世界狀態模型 → NPC 自主性 → 存檔一致性 → 新玩家開局**。完成這五項後，再擴大百科並邀請玩家測試，效益會高於單純增加咒語條目。
