# 角色立繪交付規格（給 ChatGPT／美術）

遊戲裡的角色是「2D 紙片立在 3D 場景」：一張立繪會被程式切成上身與兩條腿，做出待機、行走、互動動畫，並在 3D 中繞垂直軸旋轉（90° 只剩紙緣、180° 自動鏡像）。**所以每個角色只需要一張圖。**

## 每張立繪的要求
| 項目 | 規格 |
|---|---|
| 畫風 | 以 `assets/art-direction/` 兩張參考圖為準：柔和繪本感、細暖棕線條、暖色夕照邊光、Q 版但修長 |
| 構圖 | 單一角色、全身入鏡（頭頂到鞋底），不裁切 |
| 朝向 | 正面 3/4 **朝畫面右方**（朝左由程式鏡像） |
| 姿勢 | 自然站姿；**兩腿略微分開、看得到兩隻鞋**；雙手垂在身側，不要擋住腿 |
| 外袍 | 下襬最好在膝蓋附近或以上，讓小腿露出（行走時擺動的是下襬以下的部分） |
| 背景 | 透明 PNG；做不到就用純白或純淺灰，不要地面陰影、不要漸層 |
| 描邊 | **不要畫白色貼紙描邊**（程式會統一加暖白描邊） |
| 尺寸 | 高度至少 1000 px，角色周圍留一點空白即可 |
| 原創性 | 不要畫成既有電影／小說角色的長相（例如圓眼鏡＋額頭疤痕的男孩） |

## 檔名與放置
- 放在 `docs/sprites/<外觀名>.png`，外觀名對應 `docs/js/sprites.js` 的 `LOOKS`：
  `player`、`reader`、`curly`、`bookish`、`tall`、`librarian`、`professor`、`gardener`、`redhead`。
- 新角色可以取新名字，並在 `LOOKS` 加一筆。

## 接上遊戲
在 `docs/js/sprites.js` 的 `SPRITES` 加一行：
```js
player: { src: "../sprites/player.png" },
```
腿部範圍會從透明度自動偵測。偵測不準時可手動指定（皆為 0–1 比例）：
`hem`（外袍下緣高度）、`legs: [左, 右]`、`split`（兩腿分界）、`hand: [x, y]`（互動光點位置）。

## 驗收
打開 `docs/character-lab.html?sprite=sprites/player.png&zoom=3`：
- `&frame=4`～`11` 逐格看走路，`&frame=12`～`17` 看互動
- `&angles=1` 看 0°／45°／90°／135°／180° 對照
- 與參考圖並排比較，畫風不一致就重畫，不要用程式補

## 給 ChatGPT 的指令範本
> 請參考我上傳的遊戲畫面（霍格華茲圖書館奇遇-2.png）的畫風，畫一張遊戲角色立繪：
> 【角色描述：例如「一年級女學生，栗色長捲髮，深灰巫師袍，青綠與黃銅色條紋圍巾，棕色短靴」】
> 規格：單一角色全身、正面 3/4 朝畫面右方、自然站姿、兩腿略分開看得到兩隻鞋、雙手垂在身側；
> 透明背景（不行就純白），不要地面陰影，不要白色描邊；高度至少 1000 像素；
> 畫風、線條、上色、光影與比例要和參考圖裡的角色一致；原創長相，不要像任何既有電影角色。
