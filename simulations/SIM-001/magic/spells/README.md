# 洛夏｜咒語掌握紀錄

此處只記錄洛夏個人的咒語知識與實際掌握程度；完整魔法百科見 [全域咒語目錄](../../../../global/magic/spells/README.md)。

## 已掌握

### Wingardium Leviosa｜漂浮咒
- 來源：在家閱讀《標準咒語，初級》後自行練習。
- 已能使羽毛離開桌面。
- 能控制羽毛升降、停留、移動、轉向、穿越狹窄空隙及倒退。
- 能使木球懸浮並維持一段時間，重量增加後仍能控制。
- 初學時即展現優秀的方向與高度控制。
- Eleanor、Alexander、Theodore 均已知悉。

## 看過但尚未學會
- Lumos｜光亮咒：在課本看見，尚未正式學習。
- Reparo｜修復咒：在課本看見，尚未正式學習。

**關於「魔咒滿級」：**玩家已提出洛夏魔咒滿級，但其定義可能指魔咒領域天賦／施法能力，也可能指每一個咒語的實際熟練度。尚待玩家確認前，不將全部咒語標為已學會。若確認為所有咒語實力滿級，需建立完整逐項清單並標明適用範圍。
