## 洛夏施法能力
SIM-001 中洛夏所有天賦與施法能力均為 100/100。她不需要一般練習階段來提升已理解咒語的基本施法水準；取得咒語知識並理解其原理後，即能以該咒語允許的極限方式施展。這不會讓她自動知道未知咒語，也不會改變咒語本身的功能邊界。
