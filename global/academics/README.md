# 霍格華茲科目與課程架構

記錄課程名稱、年級、教材、教授、考試與原著課程安排。每次模擬的學生課業成績與實際能力，存放在該次模擬資料夾，不寫入全域課程百科。

## 主要科目
- 黑魔法防禦術
- 變形學
- 魔藥學
- 魔法史
- 天文學
- 符咒學
- 藥草學
- 飛行學
- 奇獸飼育學
- 麻瓜研究
- 算命學
- 占卜學
- 古代神秘文字研究
- 算術占卜學（Arithmancy，與算命學／占卜學分開）
- 幻影顯形課程（適用年齡及資格限制）

## 資料分層
- 科目天賦：角色先天潛質，存放於該模擬角色天賦表。
- 科目知識：角色實際學過的理論、教材與知識。
- 課業成績：作業、考試與教授評價。
- 實作技能：該科目內每個咒語、魔藥、植物照護或實戰項目的真實能力。

同一技能可能橫跨多個領域。不得將課程成績、科目天賦與單項技能掌握度混成一個數值。
