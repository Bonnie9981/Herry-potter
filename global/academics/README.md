# 霍格華茲科目與課程架構

## 完整科目索引
請由 [各科目百科](subjects/README.md) 進入，包含必修、選修及高年級專門課程。

## 主要必修科目
- 變形學
- 符咒學
- 魔藥學
- 魔法史
- 黑魔法防禦術
- 天文學
- 藥草學
- 飛行課（掃帚基礎課程）

## 選修科目
- 占卜學（Divination，常以算命、茶葉占卜、水晶球等方式進行）
- 算術占卜學（Arithmancy，獨立科目）
- 麻瓜研究
- 古代神秘文字研究
- 奇獸飼育學

## 高年級專門課程
- 鍊金術等專門課程，依需求開設。

## 名稱釐清
原著正式科目是 Divination，台灣語境通常稱「占卜學」；「算命」是常見的占卜方式或通俗說法，並非另一門獨立的霍格華茲正式科目。Arithmancy 是另一門獨立課程，不能與 Divination 混淆。

## 資料分層
- 科目天賦：角色先天潛質，存放於該模擬角色天賦表。
- 科目知識：角色實際學過的理論、教材與知識。
- 課業成績：作業、考試與教授評價。
- 實作技能：該科目內每個咒語、魔藥、植物照護或實戰項目的真實能力。

同一技能可能橫跨多個領域。不得將課程成績、科目天賦與單項技能掌握度混成一個數值。
