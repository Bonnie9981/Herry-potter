# 召喚、移動與操控魔法

| 咒語／技術 | 效果 | 注意 |
|---|---|---|
| Accio | 召喚物件 | 目標辨識、距離與防護會影響成功 |
| Depulso | 將目標推離施法者 | 驅逐咒 |
| Wingardium Leviosa | 使物件漂浮並控制 | 漂浮咒 |
| Locomotor | 使物件移動 | 常與目標名稱搭配 |
| Ascendio | 使施法者向上升起 | 需考慮落點與環境 |
| Arresto Momentum | 減緩或停止移動中的目標 | 動量控制 |
| Mobilicorpus | 移動人體 | 目標狀態與控制需注意 |
| Portus | 將物件變成港口鑰 | 需遵守相關規範 |
| Apparition | 消影術，瞬間移動 | 技術而非一般初階咒語；有年齡、考照與分裂風險 |
| Disapparition | 消影離開原地 | 消影術的一部分 |

## 重要區別
- 召喚（Accio）是將既存目標召來。
- 召出術（Conjuration）是使物件出現，屬變形術範圍。
- 消影術（Apparition）是巫師自身移動。
- 漂浮咒是操控物件，不等於傳送。
