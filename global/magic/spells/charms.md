# 符咒與附加性魔法（Charms）

此檔逐項整理原著及明確標示的補充正典資料。下列僅為初始索引，後續應逐項補齊效果、限制、來源與分類，不視為完整清單。

| 咒語 | 常見名稱／效果摘要 | 備註 |
|---|---|---|
| Wingardium Leviosa | 漂浮咒，使物體懸浮並可操控 | 一年級課程；需正確揮杖與念咒 |
| Lumos | 光亮咒，使杖尖發光 | 魔杖照明 |
| Nox | 熄燈咒，熄滅魔杖光 | 常與 Lumos 配對 |
| Reparo | 修復咒，修復物件 | 修復能力依損壞程度及物件而異 |
| Alohomora | 開鎖咒 | 可能受防護咒限制 |
| Accio | 召喚咒，召來目標物 | 需明確目標與控制 |
| Incendio | 生火咒 | 火焰有環境風險 |
| Aguamenti | 清水如泉 | 召出水流 |
| Colloportus | 閉鎖咒 | 封閉門等入口 |
| Diffindo | 撕淌三步殺／切割咒 | 切割效果，需精確控制 |
| Engorgio | 速速放大 | 放大目標 |
| Reducio | 還原／縮小 | 縮小目標 |
| Impervius | 防水防濕咒 | 使目標不易受水影響 |
| Silencio | 無聲咒 | 使目標失聲 |
| Scourgify | 清潔咒 | 清潔物件 |
| Muffliato | 嗡嗡鳴咒 | 干擾周圍聽覺 |
| Confundo | 混淆咒 | 影響目標判斷 |
| Evanesco | 消失咒 | 使目標消失，屬較高階變形相關魔法，分類待依原著細化 |
| Finite Incantatem | 咒語終止／一般反咒 | 解除部分咒語效果 |

注意：名稱採台灣常見譯名或暫譯，正式遊戲輸出依皇家出版社版本校正。分類與譯名遇到不確定時標示待查，不猜測。
