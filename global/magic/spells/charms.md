# 符咒與附加性魔法（Charms）

符咒通常為目標增加或改變性質與功能。以下為小說及官方資料可確認的代表性索引，並非完整清單。

| 咒語 | 效果 | 備註 |
|---|---|---|
| Accio | 召喚目標物到施法者身邊 | 召喚咒；目標與距離會影響難度 |
| Aguamenti | 召出清水 | 水流量與用途依施法情境 |
| Alohomora | 開啟上鎖物件 | 不保證破解所有魔法防護 |
| Colloportus | 封鎖門或入口 | 可與開鎖、反制魔法互動 |
| Diffindo | 切割目標 | 需精準控制，可能造成傷害 |
| Engorgio | 放大目標 | 與縮小類魔法相對 |
| Episkey | 治療部分輕傷 | 具體療效有界限 |
| Evanesco | 使物件消失 | 常被歸入變形術相關範疇 |
| Finite Incantatem | 終止部分魔法效果 | 非萬能反咒 |
| Incendio | 產生火焰 | 火勢與環境風險須考慮 |
| Impervius | 使物件防水、防霧 | 曾用於眼鏡與裝備 |
| Lumos | 魔杖發光 | 常見照明咒 |
| Muffliato | 使周遭出現嗡鳴聲，阻隔竊聽 | 混血王子筆記中的咒語 |
| Nox | 熄滅 Lumos 的光 | 常與 Lumos 配對 |
| Reparo | 修復物件 | 損壞程度與物件性質會影響結果 |
| Scourgify | 清潔物件 | 清潔咒 |
| Silencio | 使目標無聲 | 靜音效果 |
| Sonorus | 放大施法者聲音 | 常見於公開場合 |
| Quietus | 解除 Sonorus 的擴音效果 | 配對咒 |
| Wingardium Leviosa | 使物件漂浮並可操控 | 一年級課程；揮杖動作與發音重要 |

## 分類注意
某些咒語可被不同資料來源放在不同分類。以原著效果為主，必要時加交叉標籤。咒語名稱的台灣譯名以皇家出版社譯本為準；未確認時保留英文。
