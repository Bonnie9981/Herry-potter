# 防禦、反制與解除魔法

| 咒語 | 效果 | 分類／限制 |
|---|---|---|
| Expelliarmus | 解除對手武裝，使魔杖或物品脫手 | 繳械咒 |
| Protego | 形成盾牌防禦 | 可抵擋部分咒語與攻擊，不是全能防護 |
| Protego Totalum | 防護一個區域 | 需施法者布置與維持 |
| Protego Horribilis | 強力防護黑魔法 | 高階防護 |
| Stupefy | 使目標昏迷 | 昏擊咒；多人連擊效果可能不同 |
| Impedimenta | 阻礙或減緩目標 | 障礙咒 |
| Petrificus Totalus | 使目標全身僵直 | 全身束縛咒 |
| Finite Incantatem | 終止部分咒語效果 | 非所有魔法都能解除 |
| Riddikulus | 以幽默意象削弱 boggart | 對付幻形怪的特定方法 |
| Expecto Patronum | 召喚護法，抵禦催狂魔等 | 高難度；依幸福記憶施展 |
| Salvio Hexia | 防護咒 | 具體效果依施法情境 |
| Cave Inimicum | 設置防止敵人靠近／發現的防護 | 防護區域 |
| Repello Muggletum | 驅逐麻瓜，使其遠離或不注意 | 隱匿保護 |
| Muffliato | 干擾周圍聽覺，避免被竊聽 | 兼具隱蔽用途 |

## 防禦層次
分開記錄個人盾牌、區域屏障、反咒、解除詛咒、隱匿防護、對特定生物防禦。不可把 Protego 當作能擋住任何魔法的絕對牆。
