## 單項咒語紀錄欄位

咒語名稱／咒語詞、分類、效果、施法條件、限制與反制、首次出現或來源、適用年級（若可確認）、原著正典層級。

## 角色能力狀態

每個模擬的角色另有自己的咒語掌握表。全域百科存在某個咒語，不代表角色學過或能施展。
