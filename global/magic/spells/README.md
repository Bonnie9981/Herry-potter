# 咒語百科索引

本百科按魔法性質分類，同一咒語可有多個標籤。此資料庫持續擴充，標示「初始索引」的檔案不是完整咒語清單。

## 條目要求
名稱、英文拼法、台版譯名、效果、分類、交叉標籤、首次出現／來源、施法限制、反制、危險性、正典層級。小說沒有提供的咒語詞或效果不得自行補造。

## 常見錯誤避免
- Protego 是盾牌咒，不是「護法咒」；「護法」通常對應 Patronus。
- Apparition 是消影術，屬移動技術，不等同普通召喚咒。
- 變形術與符咒學要依效果區分。
- 遊戲獨有咒語需獨立標記，不預設小說角色會使用。
- 全域收錄不等於任何角色已學會。
## 施法者實力
咒語百科記錄咒語本身的作用與限制；個別角色的施法表現另依 [施法效果型態系統](../../systems/casting/effect-profiles.md) 評估。每個咒語有自己的效果規格，不能將單一咒語任意放大成其他類型的魔法。
