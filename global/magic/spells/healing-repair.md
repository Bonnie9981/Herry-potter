# 治療與修復魔法

| 咒語 | 效果 | 注意 |
|---|---|---|
| Episkey | 治療部分輕傷 | 不等於處理重傷或複雜骨折 |
| Ferula | 召出繃帶與固定材料 | 偏向急救固定 |
| Rennervate / Ennervate | 使昏迷者恢復意識 | 不保證治癒昏迷原因 |
| Reparo | 修復物件 | 對嚴重損壞、特殊物件可能有限制 |
| Vulnera Sanentur | 治療特定嚴重切割傷 | 特殊治療咒，需依原著情節理解 |
| Anapneo | 清理呼吸道阻塞 | 來自較後期故事情節 |

## 魔法醫療原則
治療咒、魔藥與聖蒙果醫療是不同工具。咒語可能止血、固定或處理特定傷勢，但不能假設所有疾病、詛咒、毒素或永久傷害都能一咒治癒。
