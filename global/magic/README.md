# 魔法資料總架構

## 全域百科與個人掌握紀錄
- 全域百科記錄原著世界存在的魔法、咒語、魔藥、儀式、物品與規則。
- 個人資料夾記錄角色知道什麼、學過什麼、能施展什麼、製作成功什麼。
- 原創魔法預設留在創造它的模擬資料夾，不自動寫進全域百科。

## 咒語分類
- 符咒／附加性魔法（Charms）
- 變形術（Transfiguration）
- 防禦、反制與解除
- 治療與修復
- 召喚、驅逐、移動及操控
- 光線、火焰、水、氣候及環境效果
- 感官、記憶、情緒與心靈魔法
- 開鎖、封鎖、隱藏及防護
- 惡咒（Jinx）、咒罵（Hex）、詛咒（Curse）
- 黑魔法與不可饒恕咒
- 無聲施法、無杖施法、儀式與特殊技巧

分類可以交叉。Charms 通常為目標增添性質；Transfiguration 改變目標本質。不能因咒語有念詞就一律歸類為 Charms。

## 咒語條目欄位
英文原名、台灣繁體譯名、別名、主要分類、交叉標籤、效果、施法條件、限制、反制、風險、原著出處、正典層級、適用年級（若明確）。

## 魔藥分類
治療解毒、睡眠清醒、變形外貌、記憶情緒、毒藥危險、增強能力、特殊用途及未分類藥劑。

## 魔藥條目欄位
名稱、別名、效果、材料、材料處理、製作流程、攪拌與火候、耗時、難度、劑量、失敗風險、副作用、解藥、原著出處、正典層級。原著未公開完整配方時，不自行補造可操作步驟。

## 能力分層
天賦、魔力控制潛質、知識、單項熟練度、實際施展能力、情境表現分開記錄。
