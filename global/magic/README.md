# 魔法資料總架構

魔法資料分成兩個層級：
1. **全域百科**：記錄原著世界中的咒語、魔藥、魔法原理與分類，供所有模擬查閱。
2. **角色掌握狀態**：記錄某一角色是否知道、學過、能否施展或製作，必須放在該次模擬的個人資料夾。

## 咒語與魔法分類

咒語不是單一的「魔咒」欄位。至少要能區分：
- 符咒／附加性魔法（Charms）
- 變形術（Transfiguration）
- 防禦、反制與解除魔法
- 治療與修復魔法
- 移動、召喚、驅逐及操控
- 光線、火焰、水、氣候及環境效果
- 記憶、情緒、感官與心靈相關魔法
- 解除、開鎖、封鎖及防護
- 惡咒、咒罵、詛咒（Jinxes / Hexes / Curses）
- 黑魔法與不可饒恕咒
- 無聲施法、非語言施法及其他施法技巧

同一咒語可有主要分類與交叉標籤。Charm 與 Transfiguration 的區分依效果本質判斷：前者通常為物件／生物增添性質，後者改變其本質。咒語分類需保留原著語境，不可只按遊戲資料分類。

## 魔藥分類

魔藥依效果與用途建立獨立條目，例如：
- 治療、解毒、解咒
- 恢復、睡眠、清醒與體能
- 變形、變身與外貌改變
- 記憶、情緒、迷惑與控制
- 毒藥及危險藥劑
- 增強能力與特殊效果
- 生物相關及其他特殊魔藥

每一種魔藥應有材料、製作順序、時間、火候／攪拌方式、成品效果、風險、副作用、難度與來源。沒有原著依據的配方不得假裝是正典。
