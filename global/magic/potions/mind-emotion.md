# 情緒、記憶與控制類魔藥

| 魔藥 | 效果／用途 | 限制與倫理 |
|---|---|---|
| 迷情劑（Amortentia） | 強力迷戀／迷醉效果，氣味對不同人呈現個人化 | 不會創造真正的愛情；涉及操控與倫理問題 |
| 福來福喜（Felix Felicis） | 在有限時間內帶來幸運，使飲用者更容易做出有利選擇 | 過量或不當使用有危險；不能保證所有願望實現 |
| 忘情水（Wit-Sharpening Potion?） | 名稱與效果須依原著逐項確認 | 不將粉絲資料的名稱直接收錄為正典 |
| 真言劑（Veritaserum） | 使飲用者難以抗拒說出真相 | 不是絕對可靠的真相測謊工具；存在抵抗與反制方式 |
| 遺忘藥水（Memory-modifying potions） | 影響或抹除記憶 | 需與記憶咒區分；效果依具體藥劑 |

## 原則
情緒影響、迷戀、意志控制與記憶改變是不同作用。不可把迷情劑描述成真正愛情，也不可把真言劑當成百分之百可信的證據。
