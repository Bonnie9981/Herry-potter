# 治療、解毒與恢復類魔藥

| 魔藥 | 效果／用途 | 配方資料狀態 |
|---|---|---|
| 解毒劑（Antidotes） | 中和特定毒素或毒藥 | 依毒物而異，沒有單一萬用配方 |
| 治療疔瘡藥水（Cure for Boils） | 治療疔瘡 | 一年級常見基礎魔藥；需按教材核對完整配方 |
| 活力滋補劑（Strengthening Solution） | 恢復或增強體力 | 原著提及；細節待逐項核對 |
| 骨靈（Skele-Gro） | 促進骨骼再生 | 效果強烈且疼痛，非一般小傷藥水 |
| 狼毒藥劑（Wolfsbane Potion） | 使狼人變身期間保留理智 | 複雜且昂貴；不能治癒狼人症 |
| 曼德拉草復甦藥劑（Mandrake Restorative Draught） | 解除石化狀態 | 需成熟曼德拉草；與蛇妖石化事件相關 |
| 白鮮香精（Essence of Dittany） | 促進傷口癒合 | 草藥製劑，應與一般魔藥配方分開標記 |
| Pepperup Potion | 緩解感冒症狀 | 服用後可能冒出蒸氣 |
