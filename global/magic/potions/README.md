# 魔藥百科索引

魔藥需逐項管理，不能只記「魔藥學滿級」。本目錄記錄世界中存在的魔藥；角色是否知道配方、是否製作成功，另存於各次模擬。

## 分類
- [治療、解毒與恢復](healing-antidotes.md)
- [睡眠、清醒與狀態調節](sleep-awakening.md)
- [變形、外貌與身分](transformation-identity.md)
- [情緒、記憶與控制](mind-emotion.md)
- [毒藥與危險魔藥](poisons-dangerous.md)
- [其他特殊魔藥](other-potions.md)

## 收錄欄位
名稱、英文原名、效果、材料、製作步驟、時間、火候、攪拌、難度、劑量、失敗風險、副作用、解藥、來源、正典層級。

**原著配方不完整時，保留缺漏。** 不能用推測補齊成看似正典的配方，也不能把粉絲配方當作原著資料。
