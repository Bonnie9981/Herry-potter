# 魔藥百科

魔藥需逐項管理，不能只記「魔藥學滿級」。每種魔藥獨立一筆，至少記錄：
- 名稱、別名、分類、效果
- 材料及材料處理
- 製作順序、切法、攪拌方向與次數、火候、時間
- 難度、常見錯誤、失敗結果
- 毒性、副作用、解藥或反制方式
- 原著出處、年級或教材來源、正典層級
