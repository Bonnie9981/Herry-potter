# 單一咒語能力紀錄模板

每個角色對每個已知咒語獨立記錄。未學過的咒語不能因該領域天賦高就直接標為已掌握。

| 欄位 | 記錄內容 |
|---|---|
| 咒語 | 名稱／咒語詞 |
| 分類 | 符咒、變形、防禦、治療、黑魔法等 |
| 知識狀態 | 未知／聽過／讀過／理解原理 |
| 學習狀態 | 未學／教學中／已學會 |
| 熟練度 | 0–100，該咒語專屬 |
| 成功率 | 在指定條件下多次施法的成功比例或區間 |
| 強度 | 該咒語效果力量 |
| 精度 | 目標與效果控制 |
| 範圍 | 距離、面積、目標數 |
| 持續時間 | 效果維持時間 |
| 穩定性 | 重複施法一致程度 |
| 施法速度 | 完成速度 |
| 效率 | 魔力消耗與效果比例 |
| 代表性紀錄 | 實際施法案例與條件 |
| 限制 | 施法者、目標、環境、咒語本身的限制 |

## 成功率與能力分數的區別
熟練度 80 不等於每次成功率必定 80%。熟練度是綜合技能評估；成功率需在特定條件下觀察。施法者受傷、疲倦、受干擾時，結果可能下降。

## 個人風格
同一咒語可以有不同風格：力量型、精準型、快速型、節能型、多目標型、持續控制型。風格不是固定職業，角色可逐漸形成自己的組合。
