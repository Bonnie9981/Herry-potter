# 施法與魔法效果衡量系統

本系統衡量「角色實際施展某一個魔法時的表現」，不以單一總等級決定一切。不同咒語的功能不同，評估維度必須按咒語特性選用。

## 一、單次施法表現向量
每次施法可記錄以下維度，採 0–100：
- 成功度：是否完成預期效果。
- 效果強度：魔法效果的力量或作用程度。
- 輸出量：施放的魔力規模。
- 控制精度：能否精確指定目標、形狀、方向、邊界。
- 範圍：可影響的距離、面積或目標數。
- 持續性：效果能維持多久。
- 穩定性：施法過程及效果是否穩定。
- 速度：施法準備與完成速度。
- 效率：達成效果所需魔力與代價。
- 抗干擾：受壓力、移動、環境或對抗影響時維持效果的能力。

不是每個咒語都需要所有維度。譬如照明咒不必評估破壞力；治療咒不應以爆發輸出當作優劣。

## 二、施法結果分級
| 表現 | 常見結果 |
|---|---|
| 0 | 完全失敗、沒有可辨識效果 |
| 1–10 | 火花、微弱閃光、短暫顫動等不完整反應 |
| 11–25 | 效果出現但極弱、不穩定或常偏離目標 |
| 26–40 | 基本效果勉強成立，控制與持續性有限 |
| 41–55 | 一般合格施法，可完成標準用途 |
| 56–70 | 熟練施法，效果穩定且能適度調整 |
| 71–85 | 高階表現，強度、範圍或精度顯著突出 |
| 86–95 | 專家級，能在複雜情境中維持高品質效果 |
| 96–100 | 極限表現；只適用於該咒語與情境的合理上限，不代表無限魔力 |

## 三、施法結果不是天賦分數
施法輸出由多因素共同決定：
1. 是否知道該咒語及其原理。
2. 是否學會正確咒語、發音、魔杖動作與施法意圖。
3. 該咒語的熟練度與實戰經驗。
4. 相關天賦（如魔力控制、輸出潛質、精細操作、該領域天賦）。
5. 魔杖相容性與狀態。
6. 當下魔力狀態、體力、情緒、專注力。
7. 目標的性質、距離、環境與對抗力量。
8. 咒語本身的限制與施法者所處年代的知識。

## 四、同一咒語的個體差異
同樣是火焰咒：
- 初學者可能只有火花、煙或短暫小火苗，甚至完全失敗。
- 基礎熟練者能點燃指定物件，火焰規模有限。
- 熟練巫師能穩定控制火焰大小、方向與持續時間。
- 高階巫師可能形成大範圍火焰或複雜火焰形態，但必須有對應咒語知識、魔力輸出、控制能力與情境條件。
- 極端大規模魔法不應簡化成「同一咒語加大力氣」；可能涉及不同咒語、複合魔法、特殊物件、儀式或劇情條件。

## 五、不要讓單一數值限制可能性
數值是主持人保持一致性的工具，不是角色行動的硬性天花板。允許新型施法技巧、個人化咒語、複合效果、魔法研究與意外突破。新效果需記錄原理假設、條件、代價、風險與已驗證程度。
