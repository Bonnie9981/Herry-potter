# 魔法效果型態與實力尺度

## 為什麼不採用單一「威力值」
不同魔法的目的完全不同。照明咒的優秀表現是亮度、穩定、照射範圍與耗能；治療咒重視療效、精度與安全；防護咒重視承受能力、覆蓋範圍與持續時間。不能用火焰規模衡量所有咒語。

## 每種魔法建立效果型態
一個咒語可同時有多種型態，主持人按實際效果選取指標：

| 效果型態 | 核心衡量維度 |
|---|---|
| 元素／能量（火、水、光、電等） | 強度、規模、範圍、形態控制、持續、熱量／能量效果、穩定性 |
| 操控／移動 | 負載、速度、距離、精度、同時目標數、穩定性 |
| 防護／屏障 | 抵抗強度、覆蓋範圍、持續時間、選擇性、抗穿透 |
| 束縛／限制 | 作用速度、限制程度、持續、目標數、解除難度 |
| 治療／修復 | 修復程度、精度、速度、組織完整性、副作用、適用範圍 |
| 變形 | 轉換完整度、複雜度、目標規模、穩定性、可逆性 |
| 感知／資訊 | 感知距離、解析度、辨識準確度、抗干擾、資訊範圍 |
| 心靈／記憶 | 作用深度、精度、持續、目標抵抗、倫理與法律風險 |
| 召喚／傳送 | 距離、目標重量／數量、定位精度、安全性、成功率 |
| 附魔／持續效果 | 效果強度、持續時間、觸發條件、作用範圍、穩定性 |
| 占卜／預言 | 資訊片段完整度、時間範圍、象徵清晰度、可解讀性、可控程度 |

## 各項指標 0–100 的意義
- 0：沒有可辨識效果或完全失敗。
- 1–10：微弱反應，例如火花、微光、短暫顫動。
- 11–25：效果存在但很弱，容易失控或中斷。
- 26–40：基本效果成立，限制明顯。
- 41–55：一般合格水準。
- 56–70：熟練，能穩定完成常規用途。
- 71–85：高階，具明顯優勢。
- 86–95：專家級，能在複雜條件下維持高品質。
- 96–100：該效果型態在此咒語／魔法機制下的極限水準。

**100 是相對於該咒語及效果型態的上限，不是所有咒語共用的絕對能量單位。** 不同咒語的 80 也不一定有相同破壞力或作用範圍。

## 咒語本身的天花板
每個咒語有自己的「效果規格」：
- 基本用途：原本設計用來做什麼。
- 可調參數：可否調整強度、大小、範圍、方向、持續時間、目標數。
- 理論邊界：原著明示或可合理確認的限制。
- 施法者可塑性：施法者能否透過控制改變效果。
- 變體與進階技巧：是否存在不同版本、複合施法或高階應用。

不能因施法者很強，就讓一個只負責照明的咒語變成爆炸咒。若要創造超出原咒功能的效果，必須是已知的其他咒語、複合魔法、特殊技巧或模擬專屬原創研究，並記錄其機制。

## 火焰例子：從火花到火海
以火焰相關魔法作示意，並非宣稱以下每一階段都是同一個咒語的標準效果：

1. **失敗／火花**：咒語沒有完成，只有火星或煙。
2. **微弱火苗**：點燃小型目標，火焰短暫且難以控制。
3. **基本火焰**：能點燃指定目標，維持穩定火苗。
4. **熟練控制**：能調整火焰大小、方向、距離與持續。
5. **高階塑形**：能控制火焰形狀、移動路徑或同時作用於多個目標，前提是該魔法允許。
6. **大規模火焰**：形成大範圍火焰或火焰屏障，通常需要對應高階魔法、複合技術或特殊施法。
7. **極端火海／火焰風暴**：屬重大魔法效果，必須符合具體魔法機制、代價與場景條件，不得只用「Incendio 施法威力 100」自動推導。

因此，新生可能只有火花、失敗或小火苗；一般巫師能點燃物件；熟練巫師可穩定控制；鄧不利多等頂尖巫師能使用高階或複合魔法形成大規模火焰。差距可能來自知識、魔力輸出、控制、經驗與魔法本身，而不是單純一個數字。

## 施法者的能力向量
施法者每次使用魔法時，可記錄：
- 輸出潛能（可調動的規模）
- 控制精度
- 施法速度
- 穩定性
- 效率
- 抗干擾
- 多工能力
- 創新應用能力


## 場景與後果
大規模魔法會帶來熱、煙、燃料消耗、結構損壞、氧氣變化、可見性、附帶傷害、魔力消耗及法律後果。魔法可以違反麻瓜物理直覺，但不能無視故事已建立的魔法規則與代價。
