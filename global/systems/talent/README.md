# 天賦系統總則

本系統適用於所有模擬。角色的天賦數值必須存在各自的模擬資料夾，不得將某次角色數值當成其他模擬的預設值。

## 核心原則
天賦不是熟練度，也不是知識量，更不是當下輸出。每一種天賦以 0–100 評分，但不同天賦有不同的作用機制、成長曲線與可觀察表現。

### 通用分數參考
| 分數 | 定位 | 一般含義 |
|---:|---|---|
| 0–9 | 極低／明顯障礙 | 該面向極不擅長，可能需要替代方法 |
| 10–24 | 弱 | 學習與控制明顯吃力 |
| 25–39 | 偏弱 | 需要大量指導與練習 |
| 40–54 | 普通 | 一般人常見範圍 |
| 55–69 | 良好 | 比平均容易掌握 |
| 70–84 | 優秀 | 學習快、理解或操作表現突出 |
| 85–94 | 卓越 | 極少見，能快速掌握複雜內容 |
| 95–99 | 頂尖 | 罕見天才級潛能 |
| 100 | 極限天賦 | 此項天賦的理論上限；可能出現直覺理解、無師自通或近乎本能的表現，具體效果依天賦種類而定 |

分數是模擬用的能力模型，不是原著世界中的官方數值。

## 天賦類別
每個角色應逐項列出，而不是只給「魔法天賦」一個總分。可依角色與世界觀擴充：
- 認知類：邏輯推理、記憶、模式辨識、空間想像、創造力、專注力。
- 魔法感知類：魔力感知、魔法結構直覺、魔法辨識、魔法適應力。
- 施法類：魔力控制、精細操作、輸出調節、穩定性、施法速度、無聲施法潛質、無杖施法潛質。
- 科目／專業類：變形學、符咒學、魔藥學、魔法史、黑魔法防禦術、天文學、藥草學、飛行、魁地奇專項、奇獸飼育學、麻瓜研究、占卜學、算術占卜學、古代神秘文字、鍊金術等。
- 特殊類：預言能力、破心術潛質、大腦封閉術潛質、阿尼馬格斯變形適性、護法咒適性等。只有設定或世界觀允許時才建立，不可因聰明而自動獲得。

## 每種天賦必須定義自己的效果
例：
- 記憶力：影響記住內容的速度、保留率與提取準確度；不會讓角色記住從未接觸的資料。
- 邏輯推理：影響從已知資訊推出結論的能力；不能憑空知道缺失前提。
- 魔力控制：影響輸出細緻度、穩定性與微調能力；不會自動知道咒語。
- 魔力輸出潛質：影響可調動的輸出上限；不等於控制力。
- 魔法直覺：可能讓角色在接觸魔法現象時迅速理解原理或察覺異常；不能讀取未接觸的秘密。
- 占卜／預言：若設定為真正的先天預言能力，可能在無正式訓練下出現片段預兆；不代表可自由選擇時間、內容與準確度。課堂占卜技巧與真正預言能力分開。
- 魔藥天賦：影響材料觀察、步驟節奏、火候與誤差修正；不會自動知道未知配方。

## 100 分不是全知全能
100 代表該項先天能力達到設定上限。若天賦是直覺型，可能無師自通；若是身體協調型，可能天生表現出色；若是學習型，則代表極快掌握。它不會自動授予外部知識、經歷、材料、工具、魔法資格或不屬於該天賦範圍的超自然能力。

## 天賦、知識、熟練度、實際表現分開
- 天賦：出生／設定帶來的潛能。
- 知識：角色實際接觸、閱讀、理解的資訊。
- 熟練度：練習後形成的操作能力。
- 經驗：實際情境中的應用與判斷。
- 當下狀態：疲勞、情緒、傷勢、環境、魔力狀態、工具與干擾。
- 實際表現：以上因素共同形成的結果。

## 不同模擬
每次模擬開始時，建立獨立天賦表。未指定的數值可依角色背景合理生成或詢問玩家；不得沿用前一次模擬的天賦。角色可擁有 100 分的多項天賦，也可以有明顯短板。
