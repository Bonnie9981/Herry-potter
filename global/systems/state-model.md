# 模擬世界狀態模型

本文件是每次模擬共用的狀態欄位規格。實際資料應寫入各自的 simulations/SIM-XXX/，不將任何角色數值或世界線寫進 global。

## 1. 時間與場景
- 模擬日期：
- 星期／學期／學年：
- 時段：
- 當前地點：
- 場景開始時間：
- 已經過時間：
- 場景中人物：
- 場景目標／正在處理的事：

## 2. 玩家角色狀態
- 身體狀態：健康、疲勞、傷勢、飢餓、睡眠等。
- 情緒狀態：只記錄有助於連續性的當下狀態，不用單一數字取代情緒。
- 魔法／體力／其他資源：只在該世界需要時追蹤。
- 當前限制：受傷、裝備不足、禁令、時間壓力等。
- 已知資訊：角色實際知道的事。
- 當前目標：玩家明確提出或已接受的目標。

## 3. 物品與資源
每件重要物品記錄名稱、數量、品質、狀態、持有人、存放位置、取得來源及消耗／轉移紀錄。
金錢、材料、藥劑、食物及可消耗資源需有明確增減紀錄。不可無來源增加物品，也不可在未描述的情況下消失。

## 4. 角色知識與能力
知識、天賦、熟練度、經驗、裝備加成與當下狀態分開記錄。技能需記錄取得來源、目前階段、已知限制及最近一次使用結果。
玩家知道但角色不知道的原著資訊，另存為玩家層知識，不可直接當成角色行動依據。

## 5. 任務、線索與承諾
每筆紀錄包含：
- ID：
- 名稱：
- 類型：主線／支線／個人目標／承諾／線索。
- 狀態：未發現／已發現／調查中／暫停／完成／失敗／錯過。
- 來源與發現時間：
- 已知事實：
- 尚未證實的假說：
- 下一個可行調查方向：
- 時間窗口及錯過後果：
- 關聯人物、地點與物品：

假說不得寫成已確認事實。任務失敗需保留失敗原因與世界後果。

## 6. 世界事件與因果
每個重要事件記錄事件 ID、時間、地點、參與者、目擊者、事件內容、直接結果、延遲影響、玩家是否知情、NPC 是否知情及資訊傳播方式。
重大世界線變動需額外記錄原著預期、玩家介入、立即差異、可能後續及尚未確定之處。

## 7. 每次行動後的更新檢查
- [ ] 時間是否推進合理？
- [ ] 地點與移動是否連續？
- [ ] 物品、金錢、材料是否有來源與去向？
- [ ] 玩家與 NPC 知識是否正確？
- [ ] 關係變化是否有互動依據？
- [ ] 任務與線索狀態是否更新？
- [ ] 事件是否留下時間線紀錄？
- [ ] 是否產生新的待確認事項？

## 8. 快照建議
每次重要場景結束、跨日、長途移動、重大決策、角色受傷、關係重大變化或任務完成後，建立一次狀態快照。快照應簡短且可恢復，不需重複整份角色百科。
