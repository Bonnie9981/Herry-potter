# 道具、環境物件與互動系統

## 核心概念
世界中的物件不只是敘述背景，而是有狀態、可觀察資訊、可採取行動及合理限制的互動節點。互動不必由預設選單限制；玩家提出新方法時，主持者依物件功能與世界規則判斷。

## 一、物件類型
- **個人物品**：魔杖、課本、筆記、衣物、寵物用品、零錢。
- **消耗品**：食物、藥劑、材料、墨水、羊皮紙。
- **工具與裝備**：坩堝、天平、望遠鏡、掃帚、護具。
- **知識物件**：書籍、報紙、地圖、信件、照片、羊皮紙紀錄。
- **互動環境**：門、窗、樓梯、壁爐、桌椅、櫃子、機關、肖像。
- **生物與半自主物件**：寵物、魔法生物、幽靈、肖像、具自主反應的魔法器具。
- **特殊魔法物件**：具有啟動條件、限制、代價或秘密的神器與附魔物。

## 二、物件資料欄位
重要物件才需要完整資料卡：
- ID／名稱／類型／描述
- 持有人／保管者／目前位置
- 數量／品質／材質／尺寸／重量（有意義時）
- 狀態：完好、使用中、受損、破裂、耗盡、封存、遺失等
- 耐久或剩餘使用次數（確實會消耗時才使用）
- 魔法效果／附魔／啟動條件
- 已知用途／未知用途／角色已知資訊
- 可互動動詞與前置條件
- 互動耗時、消耗、風險與可見後果
- 取得來源、交易紀錄、轉移紀錄及原著來源層級

## 三、通用互動動詞
依物件類型選用，不要求每個物件都有所有功能：
- 觀察、檢查、辨識、聞、聽、觸摸
- 拿取、放下、移動、收納、攜帶、藏匿
- 打開、關閉、鎖上、解鎖、拆卸、組裝
- 使用、啟動、停止、調整、操作、試驗
- 閱讀、翻閱、抄寫、比較、搜尋、標記
- 填充、倒出、飲用、食用、塗抹、混合
- 修理、清潔、保養、磨利、充能（僅適用時）
- 附魔、解除、破壞、丟棄、交付、借用、交換、出售
- 與其他物件組合、以咒語影響、用工具操作

## 四、互動判定
每次互動依序檢查：
1. 目標是否存在且可接觸？角色是否能看見或找到？
2. 玩家使用的方法是否合理？角色知道這種方法嗎？
3. 是否需要工具、咒語、鑰匙、權限、材料或特定知識？
4. 物件目前狀態允許嗎？是否被鎖、封印、損壞、看守或附魔？
5. 互動消耗多少時間？是否留下聲音、痕跡、魔法殘留或目擊者？
6. 成功、部分成功與失敗分別改變哪些狀態？

不能只回覆「你點擊了物品」。必須說明可觀察結果、物件狀態變化與可能後果。

## 五、物件狀態與連鎖互動
物件可以有狀態機，例如：
- 門：關閉 → 開啟；上鎖 → 解鎖；受損 → 無法正常關閉。
- 書：未讀 → 已翻閱 → 已做筆記；受潮或缺頁會影響可讀資訊。
- 坩堝：乾淨 → 已裝材料 → 加熱中 → 成品／失敗批次 → 待清潔。
- 信件：未寄出 → 已封口 → 運送中 → 已送達 → 已閱讀／被截取。
- 藥草：種子 → 發芽 → 成長 → 成熟 → 採收；環境不合會枯萎或生病。

狀態變化必須有時間與因果。物件被拿走後，原位置不能仍然有同一件；消耗品使用後需扣除數量；借出的物品要記錄歸還狀態。

## 六、物件組合與實驗
玩家可以提出任意組合，但結果依材料性質、尺寸、知識、工具、咒語、相容性與風險判斷。未知配方可以實驗，不保證成功；失敗可能得到部分資訊、浪費材料、造成污染或危險反應。不要因為玩家說「把 A 和 B 合在一起」就自動產生有用新物品。

## 七、場景互動密度
每個重要場景應有可被發現的互動元素，而不是把所有秘密一次列出：
- 可見物件：玩家自然能注意到。
- 可調查物件：需要靠近、觀察、詢問或使用工具。
- 隱藏物件：需要線索、特定角度、咒語或條件。
- 動態物件：會因時間、NPC、天氣、魔法或玩家行動改變。
- 危險物件：操作前可提供合理警訊，但不提前揭露全部秘密。

## 八、霍格華茲互動範例（系統示例，非新增正典事實）
- 肖像：交談、詢問、觀察、請求通行；其反應依人物性格與記憶。
- 圖書館書籍：查找、借閱、翻閱、比較版本、做筆記；限制區有權限與被發現風險。
- 坩堝：檢查清潔度、放材料、控制火候、攪拌、取樣、清理。
- 門鎖：檢查鎖型、尋找鑰匙、使用 Alohomora、破壞；不同防護不保證能被同一咒語破解。
- 魔法樓梯：觀察移動規律、等待、尋找替代路線；不保證每次都到相同位置。
- 寵物：餵食、清潔、觀察健康、互動、訓練；生物有需求與個體反應，不是道具按鈕。

## 九、經濟與物品流向
交易需記錄價格、貨幣、數量、買賣雙方、時間、庫存與物品狀態。價格依店家、年代、品質、供需與議價情況；未確認的正典價格標記估值，不冒充原著價格。贈與、借用、偷竊、遺失、沒收及歸還都要留下紀錄。

## 十、互動驗收
- 同一物件狀態會跨回合保留。
- 消耗、轉移與修理有明確前後差異。
- 玩家可用自然語言提出非預設互動。
- 互動需要的知識、工具、時間與風險被考慮。
- 物件的隱藏資訊不會無條件直接顯示。
- 同一物件不會同時出現在兩個位置或兩個持有人手中。
