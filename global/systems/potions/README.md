# 魔藥製作與成品評估

魔藥不能只用「魔藥學天賦」或單一熟練度判斷。每一種魔藥、每一鍋成品都要考慮配方知識、材料、操作與成品品質。

## 魔藥製作能力
- 配方理解：理解材料功能與步驟原理。
- 材料辨識：辨識品質、成熟度、保存狀態與異常。
- 前處理精度：切割、搗碎、研磨、萃取。
- 時序控制：加入順序與時間。
- 溫度控制：加熱、冷卻與火候。
- 攪拌控制：方向、次數、速度與節奏。
- 誤差修正：發現異常並在可行範圍內修正。
- 安全操作：避免污染、毒性暴露與反應失控。
- 批次穩定性：多次製作是否一致。

## 單鍋成品評估（0–100）
按魔藥性質選用：配方符合度、效力、純度、穩定性、保存期限、藥效持續時間、雜質／副作用、批次一致性。治療魔藥重視療效與安全，變身水重視身份轉換完整性與穩定，解毒劑重視對應毒素的有效性。

## 原則
- 不知道配方不能只靠天賦憑空熬出正確藥劑。
- 高天賦能讓角色更快看出材料狀態、操作誤差及調整方向。
- 不同魔藥有不同容錯率；有些配方差一個步驟就會失敗。
- 魔藥成品不會因製作者天才就自動完美；材料品質、器具、環境與配方版本都重要。
- 原著未公開完整配方時，不得自行補成正典。
