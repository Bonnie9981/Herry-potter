# 魔法生物資料庫

## 條目標準
每種生物建立獨立條目或分類頁，記錄：名稱、分類／危險等級（如有官方依據）、棲地、外觀、習性、飲食、魔法能力、照護方式、接觸風險、法律限制與原著出處。一般動物與魔法生物要分開。

## 分類索引
- 哺乳類與大型生物：巨人、狼人、獨角獸、夜騏、鷹馬、家養小精靈等。
- 龍與爬蟲類：各種龍、蛇妖、普通蛇類。
- 鳥類與飛行生物：鳳凰、鷹馬、貓頭鷹等。
- 水生生物：人魚、格林迪洛、巨烏賊等。
- 微型與寄生生物：康瓦耳郡小精靈、炸尾螺等。
- 具有特殊能力的生物：護法相關形態、媚娃、攝魂怪等（分類需依原著）。

## 重要原則
- 生物危險等級與可否飼養依官方分類及法律資料，不自行發明。
- 普通動物不因出現在魔法世界就自動變成魔法生物。
- 角色的寵物與照護經歷只記在該次模擬。
