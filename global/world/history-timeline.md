# 魔法世界歷史年表（基礎索引）

本表只放跨模擬共用的已知歷史節點。年份不確定時標記約略年代。

| 時間 | 事件 | 備註 |
|---|---|---|
| 約 10 世紀末 | 霍格華茲由四位創辦人建立 | 葛來分多、赫夫帕夫、雷文克勞、史萊哲林 |
| 中世紀 | 巫師社群逐步與麻瓜社會隔離 | 國際保密法之前已有迫害與隱匿背景 |
| 1692 | 國際巫師聯合會制定《國際巫師保密法》 | 巫師社會對麻瓜隱匿 |
| 18 世紀 | 魔法部制度逐步成形 | 英國魔法部於 1707 年成立 |
| 1926 | 湯姆・瑞斗出生 | 伏地魔本名 |
| 1938 | 湯姆・瑞斗進入霍格華茲 | 史萊哲林 |
| 1943 | 密室事件；桃金孃死亡，海格被誣陷 | 瑞斗利用日記與蛇妖 |
| 1945 | 鄧不利多擊敗葛林戴華德 | 年份與事件屬已知歷史 |
| 1950 年代 | 部分教授與角色的任職、求學年代 | 個別人物另建檔 |
| 1970 年代 | 第一次巫師戰爭 | 伏地魔勢力擴張 |
| 1981-10-31 | 波特夫婦遇害；伏地魔失勢 | 哈利存活 |
| 1991-09-01 | 哈利・波特入學 | SIM-001 洛夏同年入學，尚未分院 |
| 1992-1993 | 密室再度開啟 | 哈利二年級 |
| 1993-1994 | 天狼星布萊克逃出阿茲卡班 | 哈利三年級 |
| 1994-1995 | 三巫鬥法大賽 | 哈利四年級 |
| 1995-1996 | 魔法部否認伏地魔回歸 | 哈利五年級 |
| 1996-1997 | 第二次戰爭擴大 | 哈利六年級 |
| 1997-1998 | 霍格華茲戰役 | 哈利七年級 |

日期如需精確到日，須以小說時間線核對。不得把不同模擬角色事件加入此全域年表。
