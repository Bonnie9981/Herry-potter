## 最重要的隔離規則
1. 全域資料庫只記錄跨模擬通用的原著設定與已確認規則。
2. 每次模擬有自己的角色、家庭、能力、物品、關係、時間線、原創內容與世界線變動。
3. 某次模擬新增的咒語、魔藥、人物、組織、地點或魔法制度，預設只屬於該模擬。
4. 玩家明確要求將原創內容升級為跨模擬共通設定後，才可複製或整理進 global；需保留「原創通用設定」標籤，不冒充原著。
5. 原著小說優先；官方補充、電影、遊戲、舞台劇及粉絲資料必須分層標示。
6. 未確認資料標示「未詳／待核對」，不可捏造填滿。
7. 每次遊戲對話結束，依實際變動更新對應檔案；只有 GitHub 寫入成功才能回報已存檔。
