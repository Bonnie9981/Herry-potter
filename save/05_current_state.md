# 05｜目前狀態與待辦

- 時間：1991 年 8 月，入學前暑假。
- 具體日期：尚未設定。
- 遊戲階段：第一次霍格華茲人生模擬，入學前。

## 目前已確認狀態

- 洛夏已收到入學通知並接受入學。
- 已完成斜角巷一年級用品採購。
- 已取得銀椴木、龍的心弦魔杖。

## 待辦

1. 等待霍格華茲回覆小羽的入校許可。
2. 持續陪伴小羽，建立固定照顧習慣。
3. 可由母親指導光亮咒 Lumos 的原理與正確施法方式。
4. 可繼續練習漂浮咒的精細控制，但注意休息與安全。
5. 洛夏對修復咒 Reparo 有興趣，尚未學習。
6. 尚未決定是否收養先前看見的灰褐色貓頭鷹。
7. 尚未決定霍格華茲學院。

## 最近一幕／續玩入口

最近一段練習結束後，洛夏回到飼養區陪小羽。小羽從躲藏屋探出頭，並逐漸願意靠近洛夏。Theodore 看到後提到小羽現在比較常出來，問洛夏是否真的很喜歡牠。

上一輪可選行動：
1. 明天繼續練習漂浮咒，挑戰更精細的控制。
2. 請母親教光亮咒的原理與正確施法方式。
3. 和 Theodore 一起陪小羽，看看牠會不會更願意主動探索。
4. 去問父親，霍格華茲有沒有回信。
5. 自由行動。

注意：以上是待選行動，不代表玩家已選擇或已執行。
